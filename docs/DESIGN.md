# Runbyte — дизайн-система

## Идея

Инженерная студия, которая *делает*, а не рассказывает. Визуальный язык — редакционный, «печатный»: тёплая бумага и чернила, крупная типографика, монопространственные подписи как на технических чертежах, плёночное зерно. Тон — уверенный, сухой, без восклицательных знаков.

Референс-ощущение: журнальная вёрстка + технический документ + тёмная студия ночью. Не «SaaS-лендинг».

## Правила «не-AI стиля»

Это чек-лист, по которому сайт собирался и по которому его нужно проверять при любых правках.

**Запрещено**
- Фиолетово-синие и cyan-градиенты, любые «mesh gradient» фоны.
- Glassmorphism: полупрозрачные карточки с blur и тонкой светлой рамкой.
- Свечение (glow, neon, box-shadow цветом акцента).
- Градиентный текст.
- Три одинаковые карточки с иконкой-эмодзи в ряд.
- Карточки внутри карточек.
- Bounce / elastic easing.
- Шрифты Inter, Roboto, Poppins, Montserrat, системные.
- Стоковые улыбающиеся люди, глянцевые 3D-блобы, «абстрактные летающие фигуры».
- Слова-паразиты в копирайте: unlock, elevate, seamless, cutting-edge, empower, leverage, next-level.

**Обязательно**
- Одна акцентная краска, применяется точечно (точка-индикатор, слово в заголовке, свет на фото).
- Реальная фотография с зерном вместо иллюстраций.
- Нумерация секций `(01)…(08)` и подписи в моно — как на чертежах.
- Тонкие линии `1px` как основной разделитель, а не тени.
- Чередование светлых и тёмных секций, чтобы страница «дышала».
- Асимметрия: заголовки секций стоят в правых двух третях сетки, а не по центру.
- Микро-детали: локальное время студии, координаты, «Fig. 01», ® у логотипа.

## Токены

| Токен | Значение | Применение |
|---|---|---|
| `--ink` | `#141311` | тёмный фон, текст на бумаге |
| `--ink-2` | `#1C1B18` | подложки на тёмном |
| `--paper` | `#EFEAE2` | светлый фон, текст на тёмном |
| `--paper-2` | `#E5DFD4` | второй светлый фон (секция цитат) |
| `--accent` | `#FF4A1F` | сигнальный оранжевый, только точечно |
| `--mute` | `#8A847A` | вторичный текст |
| линии | `currentColor` @ 16% | все разделители |

Радиусы: `4px` для картинок и кнопок, `6px` для карточек процесса, круг — только у кнопок-иконок и у «Start a project» в конце кейсов.

## Типографика

| Роль | Шрифт | Настройки |
|---|---|---|
| Display / заголовки | Bricolage Grotesque 500 | `letter-spacing: -.035…-.045em`, `line-height: .92….98` |
| Акцент в заголовке | Instrument Serif Italic 400 | `font-size: 1.08em` относительно заголовка |
| Цитаты | Instrument Serif 400 | `line-height 1.12` |
| Подписи, метки, цифры | JetBrains Mono 500 | `11.5px`, uppercase, `letter-spacing .08em` |
| Текст | Bricolage Grotesque 400 | `16–18px`, `line-height 1.5` |

Масштаб заголовков задан через `clamp()` и завязан на ширину вьюпорта — на 1440px h1 ≈ 124px, на телефоне ≈ 46px.

## Сетка и ритм

- Боковые поля `--pad: clamp(20px, 4vw, 56px)`.
- Шапка секции — сетка `1fr 1fr 2fr`: индекс, подпись, заголовок. На планшете — две колонки, заголовок переносится вниз.
- Вертикальный ритм секций `clamp(96px, 12vw, 180px)`.

## Движение

Все easing — `cubic-bezier(.16,1,.3,1)` («out») и `cubic-bezier(.76,0,.24,1)` («in-out»). Никакого bounce.

| Где | Что происходит |
|---|---|
| Loader | Тёмный экран, «Runbyte» выезжает из маски, счётчик 000→100, шторка уходит вверх. Повторный визит в сессии — короткая версия. |
| Hero | Строки заголовка выезжают из масок с задержкой, картинка раскрывается clip-path + scale, параллакс. |
| Nav | Скрывается при скролле вниз, появляется при скролле вверх. `mix-blend-mode: difference` — сама инвертируется над тёмными и светлыми секциями. |
| Manifesto | Слова заливаются из 18% в 100% по мере скролла (scrub). |
| Services | Строка при наведении заливается бумагой снизу вверх; рядом с курсором плавает превью-картинка с лёгким наклоном по скорости мыши. Клик — аккордеон. |
| Work | На десктопе секция пинится и кейсы едут горизонтально; внутри картинок — лёгкий параллакс. На мобиле — вертикальный список. |
| Process | Sticky-карточки складываются стопкой, предыдущая слегка уменьшается и темнеет. |
| Numbers | Счётчики. |
| Quotes | Слайдер с автопереключением. |
| CTA | Заголовок с оранжевым словом, огромный e-mail с исчезающим подчёркиванием, магнитная кнопка. |
| Footer | Огромный wordmark с параллаксом, обрезанный по низу. |
| Курсор | Точка с `difference`; на ссылках увеличивается, на кейсах превращается в оранжевый круг «View case». |

`prefers-reduced-motion: reduce` отключает всё, кроме состояний наведения; контент виден сразу.

## Как добавлять секции

1. Секция = `<section class="section">` + `.section__head` с индексом и подписью.
2. Тёмная секция — добавить `--bg: var(--ink); --fg: var(--paper)` на класс секции (см. `.services`).
3. Появление элементов — атрибут `data-reveal`; картинки — `data-clip` на `figure` и `data-parallax="0.15"` на `img`; заголовки — `data-split="lines"`.
