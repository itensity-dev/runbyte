# Runbyte — дизайн-система (v2, «running bytes»)

## Идея

Название = *run* + *byte*. Весь визуальный язык построен на этом: байты «бегут», буквы собираются из точек, как на флип-дот табло, надписи прощёлкиваются как на механическом сплит-флап табло в аэропорту. Тон — инженерный, точный, без глянца.

Референс-ощущение: пультовая ночью, старое табло вокзала, техническая спецификация. Не «SaaS-лендинг», не «AI-glow».

## Правила «не-AI стиля»

**Запрещено**
- Фиолетово-синие и cyan-градиенты, mesh-фоны, свечение (glow/neon), градиентный текст.
- Glassmorphism: полупрозрачные карточки с blur и светлой рамкой.
- Три одинаковые карточки с иконками в ряд, карточки внутри карточек.
- Bounce / elastic easing.
- Шрифты Inter, Roboto, Poppins, Montserrat, системные.
- Стоковые фото людей, 3D-блобы, абстрактные летающие фигуры.
- Слова-паразиты: unlock, elevate, seamless, cutting-edge, empower, leverage.

**Обязательно**
- Одна акцентная краска — флип-дот жёлтый `#FFC940` — только точечно: слово в заголовке, номер, индикатор, прогресс.
- Ни одной фотографии: визуалы процедурные (canvas, SVG-схемы, табло).
- Нумерация секций `(01)…(07)`, подписи в моно, «REV 2026.09» — как в спецификации.
- Тонкие линии `1px` как единственный разделитель. Никаких теней.
- Одна светлая секция (Stack + FAQ) посреди тёмной страницы, чтобы ритм не засыпал.
- Углы прямые. Скруглений нет нигде, кроме ячеек табло (0.06em).

Archivo — variable-шрифт с осью ширины. Расширенное начертание в заголовках даёт «индустриальный» характер, который не спутать с дефолтным гротеском.

## Фирменные компоненты

**Флип-табло (`.flap-board`).** Ячейки с горизонтальной линией-шарниром. JS прокручивает символы алфавита до целевого с ускоряющимся стаггером, каждый тик — короткое сжатие по вертикали (`scaleY`). Используется в лоадере и футере (перещёлкивается при появлении и при наведении).

**Поле байтов (`ByteField`, canvas).** Слово RUNBYTE рендерится в offscreen-canvas, сэмплируется по сетке, каждая точка становится частицей. Частицы стартуют разбросанными сверху и собираются в слово с индивидуальной задержкой. Мышь отталкивает точки, по слову идёт волна яркости, отдельные точки случайно «моргают». При скролле поле гаснет. В CTA тот же класс в режиме `stream` — падающие колонки точек.

**Scramble.** Наведение на ссылки индекса, правила и e-mail прокручивает символы через `0` и `1` до исходного текста (GSAP ScrambleText).

## Движение

Easing: `cubic-bezier(.16,1,.3,1)` (out), `cubic-bezier(.76,0,.24,1)` (in-out), `cubic-bezier(.2,.9,.1,1)` для механики табло. Bounce запрещён.

| Где | Что |
|---|---|
| Loader | Табло прощёлкивает RUNBYTE, счётчик 000→100, статус BOOT → RUN, шторка уходит вверх. Повторный визит в сессии — короче. |
| Hero | Частицы собираются в слово, строки заголовка выезжают из масок, углы с метаданными проявляются. |
| Nav | Скрывается при скролле вниз. Над светлой секцией меняет палитру. |
| Statement | Слова заливаются по мере скролла. |
| Services | Sticky-индекс слева подсвечивает активную услугу; у каждой — живая SVG-схема (сетка, сигнал, волна, граф узлов, курсор). |
| Process | Секция пинится, четыре стадии едут горизонтально, жёлтая линия заполняется, readout показывает STAGE 0N. |
| Principles | Ячейка заливается жёлтым снизу при наведении, заголовок скремблится. |
| Footer | Табло с названием прощёлкивается при появлении. |

`prefers-reduced-motion: reduce` — контент виден сразу, canvas рисует статичное собранное слово.

## Как добавлять секции

1. Шапка секции: `<div class="mono …__meta"><span>(0N)</span><span>Название</span></div>` + `<h2 class="h2" data-split="lines">`.
2. Появление элементов — `data-reveal`; заголовки — `data-split="lines"`; текст с заливкой — `data-fill`.
3. Светлая секция — скопировать переопределения переменных из `.stack`, добавить её в триггер `is-light` в `main.js`.
